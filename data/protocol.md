# Protocol excerpt — ENROLBOUND-01 (synthetic)

This is a short eligibility excerpt for a fake Phase III non-squamous NSCLC study. It is not a real trial. The protocol is silent on immunotherapy washout and silent on asthma.

## Inclusion

### I1 — Histology

Histology must be non-squamous NSCLC.

### I2 — Molecular documentation

An uncommon EGFR mutation must be documented before randomisation.

### I3 — Performance status

ECOG performance status 0 or 1.

## Exclusion / permitted medicines

### E1 — Metformin

Prior metformin is permitted.

### E2 — Kidney function at screening

eGFR must be at least 60 mL/min/1.73m2 at screening.
